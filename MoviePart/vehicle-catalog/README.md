# Toyota and Lexus reference library

This library contains one exterior and one interior image for each supported Toyota or Lexus model. Folder names use the requested `<Brand>_<model>` form; `product.json` contains the lower-case ID used by the studio API.

Every image came from Wikimedia Commons under the explicit license recorded in the folder's `attribution.json`. That file preserves the author, source page, original URL, license name, local filename and any thumbnail transformation. Keep it with the images when copying or redistributing a folder. Follow the linked source page for the complete license terms, including attribution and share-alike obligations.

Public visibility is not permission. Do not add manufacturer press images, dealer-listing photos or other web images unless their license explicitly permits the intended use. Before using these references in advertising or generative production, verify the recorded license and confirm that the exterior and interior depict the intended generation and trim.

The library intentionally omits models for which a complete, freely reusable exterior/interior pair was not found. It never substitutes a related model's cabin or body.
